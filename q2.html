How the Action attribute works

... in my own words

The action attribute on a form tag tells the the url the destination and where the form data will be sent for processing. It also uses methods like GET and POST.

When the user presses the submit button, the browser acts a sponge and collects the values from the form's fields and sends them to that address. If the action attribute is left out, the form sends its data back to the same page it is on. The method attribute (GET or POST) works with action to decide how the data will travel.
